LLMs · MCP

Gemini + MCP for supplier support

Problem
Agents spent long stretches piecing together context across Jira tickets and analytics data.
Approach
Designed and built a Gemini integration using MCP to bridge Jira and BigQuery, delivering ticket summaries, pattern analysis and key insights in the ticketing platform.
Result
−28% agent handle time.
  • Gemini

Platform architecture · Migration

From PHP monolith to federated microservices

Problem
The global customer support platform lived inside a company‑wide PHP monolith, joined by fragmented point‑to‑point integrations.
Approach
Led its extraction into Java/Spring Boot services behind GraphQL federation, and built a unified Kafka event interface with multi‑data‑center topic mirroring.
Result
Zero migration downtime, and a single source of truth for every customer‑support journey interaction.
  • Java
  • Spring Boot
  • GraphQL federation
  • Kafka

Search · Reliability

Keeping mission‑critical ticketing standing

Problem
Ticketing infrastructure was heading toward capacity exhaustion, and Jira Data Center suffered Lucene index and database contention under redundant webhook load.
Approach
Designed an Elasticsearch‑backed search layer, and a Pub/Sub fan‑out that moved JQL payload serialization off the application nodes.
Result
<25ms p99 over 20k daily queries, averting the projected capacity crunch and stabilizing the cluster.
  • Elasticsearch
  • Pub/Sub
  • Jira DC
